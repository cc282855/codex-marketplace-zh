## V1.0 的具体功能

V1.0 定义了一套面向真人短剧、影视剧、电影、广告及其他视听项目的资产自动生成流程：

1. **项目输入与信息优先级**：读取剧本、资产文件或同时包含两者的项目文件夹；以资产文件中的明确描述为最高优先级，并按剧本与既有世界观补齐未指定信息。
2. **世界观与资产管理**：建立、更新 World Bible；识别人物、场景、道具；合并重复资产，并维护内部结构化资产数据。
3. **人物资产与选角**：为人物生成多候选方案和标准多视图资产；支持基础造型、角色选择、Casting Lock、换装时的身份延续，以及跨角色人脸去重。
4. **场景与道具设计**：按资产约束生成多个差异化的场景设计方案；锁定关键场景元素；为道具创建独立图，并处理特殊状态。
5. **提示词与视觉控制**：采用五层提示词结构，在生成前检查约束覆盖；以统一视觉风格、质量基线和世界观一致性控制输出。
6. **质量保障与生成执行**：逐图检查人物、场景和道具质量；对不合格结果自动重生成（最多五次）；支持执行器解耦、OpenAI 默认执行器、失败处理和禁止“假完成”。
7. **批处理、断点与可追溯性**：支持自动分批、人物批量选角、断点续跑与已完成资产保护；保存提示词、质检记录、源文件清单、生成配置及最终项目报告。
8. **交付规范**：定义目录结构、Windows 兼容命名、完成条件、交互原则、重运行增量策略与用户结果说明。

## V1.1 的具体功能

V1.1 **完整保留 V1.0 的全部能力**，并增加“主要角色颜值与镜头吸引力硬规则”，且将该规则接入提示词、质量检查与最终执行原则：

1. **主要角色的默认选角标准**：在不与剧本、资产文件的年龄、性别、族裔、职业、阶层、时代、世界观或明确外貌要求冲突的前提下，主要角色默认采用高颜值、上镜、有辨识度、具电影镜头吸引力的真人演员形象。
2. **角色气质与审美方向**：男性主要角色可按冷峻精英、成熟权势、贵公子、危险迷人等方向塑造；女性主要角色可按明艳、清冷、知性、贵气、强势等方向塑造，且必须服务于人物身份与剧情功能。
3. **影视级真实皮肤标准**：要求健康、干净、真实的皮肤质感与自然毛孔，明确排除塑料皮、蜡像感、过度磨皮和廉价美颜滤镜。
4. **辨识度与去模板化**：五个候选均需有演员感和镜头吸引力，同时在脸型、五官组合、轮廓等方面明显不同，避免重复的 AI 网红脸或男模脸。
5. **尊重原始设定**：若剧本或资产文件明确规定普通、丑陋、苍老、病态、伤疤、脏乱等外观，必须如实执行；新增规则不得覆盖既有硬性设定。
6. **提示词硬性表达与质检**：主要角色提示词必须包含与身份相匹配的高颜值、上镜、真实健康皮肤及角色辨识度描述；质检会检查角色是否达标，同时识别模板化面孔风险。
