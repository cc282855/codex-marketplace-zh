# 插件页面中文翻译

运行本插件的启用脚本：

~~~bash
node scripts/enable-plugin-marketplace-zh.mjs
~~~

脚本优先连接已经以本地调试模式打开的 Codex，并立即注入翻译与对齐规则。

- 如果 Codex 尚未运行，脚本会以仅本机调试端口启动它，然后自动注入规则。
- 如果普通 Codex 已在运行但没有调试端口，绝不关闭或重启它；脚本会更新桌面的“启动 Codex 中文插件.cmd”，规则会在用户下次从该入口打开 Codex 时自动生效。
- 翻译只改动仍为英文的插件名称、分类和简介；已有中文保持不变。
- 不要手工修改 Codex 安装包，也不要关闭用户正在使用的 Codex 窗口。

完成后报告脚本的实际结果；只有在脚本确认注入成功时，才能说当前插件页已生效。
